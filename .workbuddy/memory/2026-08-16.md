## 晚间 BugFix + 下载答疑（software-bugfix-account-wizard 已删）
- **Bug**：/wizard「申请账号（打开注册引导）」按钮点击无反应
  - 根因：web/src/pages/WizardPage.tsx 的 handleStart 原仅 `await api.accountStatus(); setAccount(s)`，未 window.open、未推进向导状态 → UI 无变化
  - 修复：新增 `CDS_REGISTER_URL="https://cds.climate.copernicus.eu/"`，重写 handleStart 在点击手势内**同步** `window.open` + `setAccount({state:"WAIT_USER"})`（必须同步，否则弹窗被浏览器拦截反而无反应）
  - QA 独立回归 PASS（无回归、构建无退化 1010 modules / gzip 156KB），仅前端改动
- **用户答疑："存在块重试耗尽"**
  - 机制：下载按 dataset→variable→year→month 切块并发；某块失败按指数退避重试（默认 retry_max=3，间隔 30s→60s，封顶 600s，jitter±10%）；重试耗尽 mark_failed("BUSY_AFTER_RETRIES")，任务级只要有 failed 块即提示"存在块重试耗尽"
  - **实现细节（重要）**：真实模式 `cdsapi.Client()` 异常**未映射**为 RetryableError（仅 mock 的 FakeCdsClient 抛 RetryableError），故真实模式遇 CDS 异常是一次失败即 failed、不重试；但任务 message 统一写"存在块重试耗尽"——真实模式下该文案指"该块下载失败"，failed 块 error 字段带真实异常字符串（如 Authentication failed / HTTP 429 / Unknown dataset）
  - 常见根因排序：①未在 CDS 网站 Accept 对应数据集许可条款（最高频）②~/.cdsapirc 的 key/UID 失效③服务器繁忙 429/503 限速④网络超时⑤请求参数非法（变量/区域/bbox）⑥并发过高被临时限流
  - 定位：看 data/tasks/<id>/task.json 的 error.failed_blocks / events.jsonl 真实异常；确认 .cdsapirc 内容 `url + key: <UID>:<KEY>`；登录 CDS 点 Accept 许可；降 cds_max_workers（默认4→2）、retry_max 调大
  - 待定：是否修"真实模式把 cdsapi 429/503/超时映射成 RetryableError 以享受自动重试"（参数错误仍不重试）——用户未明确要求，暂记
