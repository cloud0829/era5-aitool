## 新增一键启动脚本 run.bat
- 用户要一个能在 cmd 直接运行前端+后端的 .bat。已生成 `D:\Desktop\era5-AItool\run.bat`。
- 机制：用 `start` 打开两个独立 cmd 窗口，分别跑后端(uvicorn)与前端(vite dev)。
- 关键绝对路径（避免 PATH 问题）：
  - PYTHON_EXE = `C:\Users\lei\.workbuddy\binaries\python\envs\default\Scripts\python.exe`
  - NPM_EXE = `C:\Users\lei\.workbuddy\binaries\node\versions\22.22.2\npm.cmd`
  - 后端：`cd backend && python -m uvicorn era5tool.main:app --host 127.0.0.1 --port 8000 --reload`
  - 前端：`cd web && npm run dev -- --port 5173`（vite 已代理 /api /ws /products → 8000）
- 已实测：后端 /docs 返回 200、前端 / 返回 200 → 脚本命令有效。
- 注：本机有 managed 与 system 两份 node；脚本固定用 managed 22.22.2，与开发期一致。
- **踩坑修正**：.bat 初版含中文，cmd 按 GBK 解析 UTF-8 字节导致命令错乱（报错 `xxx 不是内部或外部命令`）。已改为纯 ASCII（英文）版本，校验 non-ascii bytes=0、无 BOM。→ 经验：Windows .bat/.cmd 一律纯 ASCII 最稳，避免中文乱码。

## 真实下载仍失败 → 第三轮修复（team: software-bugfix-download-ready）
- 用户任务 t_20260816_151357_d612b86f（24块）仍无法下载：manifest 6块 FileNotFoundError + 18块 "process pool terminated abruptly"。
- **根因 A（P0，主因）**：cds_channel._fetch_one_block retrieve 前从不 ensure_dir 缓存目录；真实 cdsapi（0.7.7，无冒号 token → LegacyClient，Results.download 源码确认不建父目录）直接 open(target) 报 [Errno 2]；mock 的 FakeCdsClient 自带 ensure_dir 掩盖了 bug。修复：L134 加 `ensure_dir(os.path.dirname(os.path.abspath(target)))`。
- **根因 A 附带**：is_retryable_error 对 "no such file" 无匹配 → 保守可重试 → 每块退避 30/60/120s 重试 3 次才"耗尽"= 慢的元凶。修复：non_retry_hits 加 "no such file"/"not exist"/"errno 2"/"[errno"。
- **根因 B**：18块 worker 被终止（最可能：取消/父进程退出时 pool shutdown 与正在 sleep/阻塞 retrieve 的 worker 竞争，Windows 强杀子进程 → BrokenProcessPool）。加固：取消路径 `pool.shutdown(wait=False, cancel_futures=True)` + finally 幂等跳过；新增 except BrokenProcessPool 批量标记剩余块 WORKER_POOL_BROKEN；实测 12块运行中 cancel 0.46s 返回。
- **新增测试/工具**：backend/tests/test_qa_cache_dir_ensure.py（5条）+ test_qa_round2_p0_fix.py（7条，QA）；**backend/scripts/diagnose_download.py**（速度/失败原因诊断，--mock 离线模式，真实模式已实测成功：CDS 先502自动恢复→completed，提交7.39s+运行23.07s+下载3.41s/27KB，预计24块≈334s@4并发）+ scripts/README.md。
- 测试：142 → QA 补测后 **149 passed**；QA 路由 NoOne。
- **重要发现**：用户 ~/.cdsapirc 是 36 位纯 token（无冒号）→ cdsapi 0.7.7 自动走 LegacyClient（新 CDS v2），诊断脚本已兼容两种凭据。
