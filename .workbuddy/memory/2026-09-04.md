## 新增"数据管理"界面（软件团队 software-data-manager 全流程：PM→架构→工程师→QA）
- 用户需求：界面直接管理已下载 ERA5 数据。澄清范围：扁平列表+搜索过滤 / 浏览详情 / 删除（二次确认+占用保护）/ NetCDF 元数据；不做磁盘占用统计大图表。
- 设计文档：`docs/design-data-manager.md`（+2 个 mermaid 图）。技术要点：
  - 缓存相对路径反解析：`{dataset}/{var}/hourly|monthly/{year}[/{mm}[/{dd}]].nc`，freq 后 1~3 纯数字段；失败 parsed=false 降级不阻断。
  - 占用判定：读磁盘 `data/tasks/*/task.json` 仅取 running/pending 任务 blocks 的 rel_target（orchestrator 无内存全集）；删除前现场重查 + Windows PermissionError/OSError 捕获后再查 busy → 6002/6003，绝不 500。
  - NetCDF 元数据：netCDF4 1.7.4 只读头（已装、零新依赖），time 仅取 var[0]/var[-1] num2date，任何异常 {ok:false,error} 兜底。
- 后端 API：GET /api/data/files（列表，size 降序）、GET /files/metadata?path=、DELETE /files（path 单删 / paths 批删二选一）；错误码 6001≈404/6002≈409/6003≈500 追加到 config/schema.py；HTTP200+{code,data,message} 契约。
- 前端：侧边栏"数据"→ /data 页；DataPage + FileTable + FileStatusChip + FileDetailDrawer + DeleteFileDialog；批删手拼 ?paths=a&paths=b 规避 axios 数组坑。
